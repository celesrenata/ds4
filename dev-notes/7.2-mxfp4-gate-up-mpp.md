# 7.2 — MXFP4 Gate/Up TensorOps Pair+SwiGLU Implementation

**Status:** Implemented  
**Validates:** R6, R7, R9

---

## 1. Decision

Native-MX is **deferred** (task 5.6: macOS 27 not available). The implementation uses the **staged-dequant TensorOps mechanism** from task 6.5: MXFP4 weight blocks are dequantized to half in threadgroup memory, then consumed by `matmul2d` with `execution_simdgroups<4>`.

The kernel is instantiated from the existing `kernel_mul_mm_id_pair_swiglu_mpp` template (task 7.3 infrastructure), adding an MXFP4-specific instantiation with `dequantize_mxfp4` (float-domain E8M0 scale × E2M1 LUT decode).

---

## 2. What Was Added

### Metal shader (metal/moe.metal)

The kernel was already present from the `kernel_mul_mm_id_mpp_pair_swiglu_f16_impl` template, instantiated as:

```metal
typedef decltype(kernel_mul_mm_id_mpp_pair_swiglu_f16_impl<block_mxfp4, 2, dequantize_mxfp4>)
    mul_mm_id_mpp_pair_swiglu_mxfp4_t;

template [[host_name("kernel_mul_mm_id_mxfp4_mpp_pair_swiglu_f16")]]
kernel mul_mm_id_mpp_pair_swiglu_mxfp4_t
kernel_mul_mm_id_mpp_pair_swiglu_f16_impl<block_mxfp4, 2, dequantize_mxfp4>;
```

A comment was added at the end of the TensorOps block documenting the host-side reference.

This uses:
- `block_mxfp4` (17-byte MXFP4 block: 1 E8M0 scale + 16 packed nibble bytes)
- `nl=2` (32 values per block, 16 per half — each thread decodes one half)
- `dequantize_mxfp4` (standard float-domain E8M0 × E2M1 LUT decode → half4x4)

### Host dispatch (ds4_metal.m)

After the legacy pair_swiglu pipeline is selected for MXFP4, an MPP override block:

```c
if (use_mm_id_pair_swiglu &&
    pair_swiglu_mm_pipeline &&
    gate_type == DS4_METAL_TENSOR_MXFP4 &&
    (mpp_mask & 3) &&
    !use_mxfp4_mm_id_pair_swiglu_compact_tile &&
    getenv("DS4_METAL_DISABLE_MXFP4_MOE_GATE_UP_MPP") == NULL) {
    id<MTLComputePipelineState> mpp_pair =
        ds4_gpu_get_mul_mm_id_pipeline(
            "kernel_mul_mm_id_mxfp4_mpp_pair_swiglu_f16", false);
    if (mpp_pair) {
        pair_swiglu_mm_pipeline = mpp_pair;
        atomic_fetch_add_explicit(&g_ctr_moe_gate_up_tensorops, 1, memory_order_relaxed);
    }
}
```

---

## 3. Dispatch Logic

| Condition | Result |
|-----------|--------|
| M5 + TensorOps available + MXFP4 + non-compact tile + not disabled | TensorOps pair+SwiGLU kernel |
| Pipeline lookup fails (old SDK, no DS4_METAL_HAS_TENSOR) | Fallback to legacy simdgroup kernel |
| Compact tile path (pre-M5 small-expert-bucket optimization) | Legacy simdgroup kernel |
| `DS4_METAL_DISABLE_MXFP4_MOE_GATE_UP_MPP` set | Legacy simdgroup kernel |
| `DS4_METAL_DISABLE_TENSOROPS` set (global rollback) | Legacy path (mpp_mask = 0) |

---

## 4. Kernel Characteristics

| Property | Value |
|----------|-------|
| Tile geometry | NR0=64 × NR1=32 × NK=32 |
| Threads per threadgroup | 128 (4 simdgroups × 32) |
| Threadgroup memory | 16384 bytes |
| Staging layout (K-loop) | sa_gate: 4096 + sa_up: 4096 + sb: 2048 = 10240 |
| Output layout (epilogue) | sc_gate: 8192 + sc_up: 8192 = 16384 |
| Weight dequant | dequantize_mxfp4 (E8M0 float scale × E2M1 float LUT → half) |
| Activation staging | float2x4 → half2x4 bulk convert |
| Matmul | Two matmul2d calls per K-step (gate, up) sharing activation tile |
| Cooperative accumulators | Two independent float cT (gate, up) |
| Epilogue | Identical SwiGLU to legacy: clamp + SiLU + route_weight |
| Buffer interface | Identical to legacy pair_swiglu (same encode function works) |

---

## 5. Legacy Fallback Preserved

The existing `kernel_mul_mm_id_mxfp4_pair_swiglu_f16` (and its half_scale / tail_cull / compact_tail variants) are NOT removed. They remain the default on:
- Pre-M5 hardware
- Compact tile path (small expert buckets)
- TensorOps disabled
- Old SDK builds (no DS4_METAL_HAS_TENSOR)

---

## 6. Counter Integration

The `g_ctr_moe_gate_up_tensorops` counter is incremented when the MPP pipeline is selected. Visible via existing diagnostics dump.

---

## 7. Rollback

- **Global:** `DS4_METAL_DISABLE_TENSOROPS` (kills all TensorOps dispatch)
- **Specific:** `DS4_METAL_DISABLE_MXFP4_MOE_GATE_UP_MPP` (MXFP4 gate/up only)
