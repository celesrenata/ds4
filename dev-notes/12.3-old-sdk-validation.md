# 12.3 Old-SDK / No-TensorOps Build Validation

**Requirement:** R8 — When compiled on a toolchain that lacks the needed tensor
headers/features, the legacy Metal backend SHALL build successfully without
source edits.

**Environment:** This validation was performed by code inspection on NixOS
(no macOS toolchain available). The analysis verifies that ALL new TensorOps
code is properly guarded by conditional compilation, ensuring the legacy Metal
path compiles standalone on SDKs older than macOS 26.0.

---

## 1. Compile-Time Feature Detection (ds4_gpu.h)

The header defines a tiered SDK detection scheme:

```c
#if __MAC_OS_X_VERSION_MAX_ALLOWED >= 260000
# define DS4_METAL_SDK_TENSOROPS 1
#endif
#if __MAC_OS_X_VERSION_MAX_ALLOWED >= 260300
# define DS4_METAL_SDK_COOP_INPUT 1
#endif
#if __MAC_OS_X_VERSION_MAX_ALLOWED >= 260400
# define DS4_METAL_SDK_NATIVE_INT 1
#endif
#if __MAC_OS_X_VERSION_MAX_ALLOWED >= 270000
# define DS4_METAL_SDK_NATIVE_LOWBIT 1
#endif
```

When the SDK is older than 26.0, all macros default to 0:

```c
#ifndef DS4_METAL_SDK_TENSOROPS
# define DS4_METAL_SDK_TENSOROPS 0
#endif
```

**Verdict:** Tiered fallback is correct. Non-Apple platforms and old SDKs get
all-zero capability, and the host code uses these purely as value macros (never
as `#ifdef` that would misbehave when defined to 0).

---

## 2. Shader-Level Guards

`DS4_METAL_HAS_TENSOR` is injected at Metal library compile time via
`MTLCompileOptions preprocessorMacros` **only when
`g_metal4_tensor_api_enabled` is true** (ds4_metal.m line ~6657).

## 3. Host-Side Guards (ds4_metal.m)

### 3.1 Metal Library Compilation

The `DS4_METAL_HAS_TENSOR` preprocessor macro is only injected when
`g_metal4_tensor_api_enabled` is true (line ~6657). When the variable is false
(old SDK / failed probe / rollback), TensorOps shader code is never compiled
into the Metal library.

### 3.2 Runtime Dispatch

All TensorOps dispatch goes through `ds4_gpu_mpp_available()`:

```c
static int ds4_gpu_mpp_available(void) {
    return g_metal4_tensor_api_enabled && !g_quality_mode;
}
```

This returns 0 when:
- The SDK doesn't support TensorOps (`g_metal4_tensor_api_compile_supported = 0`)
- The compile probe fails
- The global rollback is active
- Quality mode is enabled

All callers — `ds4_gpu_routed_mm_mpp_mask()`, indexer dispatch, dense
dispatch, decode crossover — check this before touching TensorOps pipelines.

### 3.3 SDK-Tier Feature Guards

Host code that uses newer Objective-C/Metal APIs is additionally guarded:

```c
#if DS4_METAL_SDK_COOP_INPUT
    if (@available(macOS 26.3, *)) {
        g_tensorops_coop_input_available = 1;
    }
#endif
```

When `DS4_METAL_SDK_COOP_INPUT` is 0 (old SDK), the code inside is excluded
at compile time.

---

## 4. Search for Unguarded TensorOps Code

Searched all `.metal` files for `matmul2d`, `metal_tensor`, `tensor_ops`,
`cooperative`, and `MetalPerformancePrimitives`. All occurrences are inside
`#ifdef DS4_METAL_HAS_TENSOR` blocks.

Searched `ds4_metal.m` for `#include <metal_tensor>` and
`MetalPerformancePrimitives` — both are inside the `#ifdef` block that is only
injected at Metal compile time via the preprocessor macro dictionary.

No unguarded TensorOps code was found.

---

## 5. Non-Metal Backend Impact

The `DS4_METAL_SDK_*` macros in `ds4_gpu.h` are gated on `__APPLE__` and
`__MAC_OS_X_VERSION_MAX_ALLOWED`. On non-Apple platforms (Linux/CUDA/ROCm),
they default to 0. The TensorOps capability struct and diagnostic functions
compile cleanly as no-ops.

---

## 6. Conclusion

**PASS** — Code inspection confirms the legacy Metal path compiles cleanly
without TensorOps:

1. All `.metal` TensorOps code is inside `#ifdef DS4_METAL_HAS_TENSOR`
2. The macro is only injected when the runtime probe succeeds
3. All host-side TensorOps dispatch is gated by `ds4_gpu_mpp_available()`
4. SDK-tier features use `#if DS4_METAL_SDK_*` compile-time guards with 0 defaults
5. No unguarded TensorOps references exist in any source file
6. Non-Apple builds are unaffected (macros default to 0)

**Note:** Full compilation validation requires a macOS machine with an SDK
older than 26.0 (pre-WWDC 2025 Xcode). This inspection-based validation
covers the structural correctness of all conditional compilation guards.
