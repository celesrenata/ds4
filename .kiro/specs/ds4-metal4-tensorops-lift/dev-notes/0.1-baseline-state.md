## AGENT.md Summary (key rules for this spec)

- DS4 is DeepSeek-V4-specific C inference, not a generic GGUF runner.
- Production path is whole-model Metal graph inference.
- Model loading stays mmap-backed (default); SSD streaming uses explicit buffers.
- C preferred; Objective-C where Metal requires; **no C++**.
- Correctness before speed — no unexplained drift.
- Must not break: SSD streaming, CUDA, distributed inference, Metal default.
- Keep implementation small, sharp, elegant; no slop or dead code.
- Avoid large CPU inference on macOS (VM failures risk).
- `make` for build; `make test` for unit/regression; live server tests intentional only.
