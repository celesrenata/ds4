| Q8_0 | — | Simple block-of-32 8-bit + f16 scale | Attention output; non-MoE use in this file |

## 6. Resident-Cache vs SSD-Streaming Variant Map

### Access patterns

| Pattern | Identifier | Description |
|---------|-----------|-------------|
| **Contiguous layer** | `src0s + expert * nb02` | Full expert layer in GPU memory (mmap or resident buffer) |
| **GPU-address table** | `device const uint64_t *addrs` / `*_addr_*` | Per-expert GPU virtual addresses (SSD-streamed into cache) |
| **6 explicit slot buffers** | `src00..src05` / `*_slots6_*` | 6 pre-resolved expert buffers (streaming cache) |
| **Group dispatch** | `*_group6_*`, `*_group8_*`, `*_group24_*` | Host-grouped expert batching within a resident partition |
| **Table dispatch** | `*_table_*` | `ds4_metal_q4_expert_table` for resolved lookup |
| **Masked** | `*_masked_*` + `active_mask` | Partial cache hit: only some experts resident |

### Host-side streaming infrastructure (`ds4_gpu.h`)

- `ds4_gpu_set_ssd_streaming(bool)` — enables SSD streaming mode
- `ds4_gpu_set_streaming_expert_cache_budget(uint32_t experts)` — cache size in experts
- `ds4_gpu_set_streaming_expert_cache_expert_bytes(uint64_t bytes)` — per-expert byte budget
- `ds4_gpu_stream_expert_cache_seed_selected(...)` — seed cache from routing decisions
- `ds4_gpu_stream_expert_cache_begin_selected_load(...)` — async expert load from SSD
- `ds4_gpu_stream_expert_cache_seed_experts_gpu_copy(...)` — GPU-copy seed from mapped weights
- `ds4_gpu_stream_expert_cache_reset_route_hotness()` — reset eviction heuristic per prompt
- `ds4_gpu_stream_expert_cache_release_resident()` — free resident cache
- `kernel_stream_expert_cache_validate` — GPU-side validation of cached addresses

## 7. MXFP4 Specifics

### Encoding
- **Block size:** 32 values (QK_MXFP4)
- **Value encoding:** E2M1 format, 4 bits per value (nibble-packed, 2 per byte)
- **Scale encoding:** E8M0 (single byte per 32-value block)
- **Layout:** `block_mxfp4` struct with `.e` (E8M0 scale) and `.qs` (packed nibbles)
- **Row bytes:** `DS4_MXFP4_DOWN_STATIC_ROW_BLOCKS * sizeof(block_mxfp4)` = 64 blocks for ne00=2048

### Decode LUT variants
1. **F32 LUT** (`ds4_metal_mxfp4_values[16]`) — 16 possible E2M1 decoded values
2. **Half LUT** (`ds4_metal_mxfp4_half_lut[256][16]`) — pre-scaled: `lut[E8M0_byte][E2M1_code]` → half
3. **Threadgroup-loaded LUT** — loaded per-simdgroup into threadgroup memory at kernel start

### E8M0→F32 conversion
```metal
static inline float ds4_metal_e8m0_to_f32(uchar e) {
    const uint bits = e == 0 ? 0x00400000u : (uint)e << 23;
    return as_type<float>(bits);
}
```
Special case: exponent 0 maps to `2^(-126)` (smallest normal float), not zero.

## 9. Expert Routing Shape (from code constants)

- **Typical selected experts:** 6 (`nei0 == 6`, `DS4_MXFP4_DOWN_STATIC_SLOTS = 6`)
- **Sum kernels:** `sum6` and `sum8` variants → 6 or 8 experts per token
- **Expert grouping for TP:** `ds4_tp_owns_expert(expert, ne02, tp_rank, tp_world)`
- **Prefill work dispatch:** `kernel_mul_mm_id_map0` builds expert-major token lists; `kernel_mul_mm_id_map_scatter_work` creates per-expert work items
- **Prefill tile shapes:** NR0=64 (output rows), NR1=32 (tokens), NK=32 (K-step) in MPP path
